# Code Review Instructions

This repository is an educational Modern C++17 project.

## Code Review Rules

- Review for correctness, bugs, unsafe behavior, and invalid assumptions.
- Pay special attention to parsing, numeric conversions, file handling, lifetimes, and error handling.
- Prefer clear and idiomatic C++17 without unnecessary abstractions.
- Flag poor separation of responsibilities when it materially hurts maintainability.
- Distinguish correctness issues from optional style suggestions.
- Explain why each issue matters and point to the relevant code.
- Do not implement fixes unless explicitly requested.
- When possible, guide the developer toward the solution instead of providing the full implementation.
- Do not nitpick formatting that should be handled by automated tooling.
