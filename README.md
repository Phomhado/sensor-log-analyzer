# Sensor Log Analyzer

The first project of Project Northbound.
"Mot nord. Ett steg om gangen!"

## Description

Sensor Log Analyzer is a command-line application written in Modern C++.

Its purpose is to read vessel sensor logs, validate them, detect malformed entries, and produce useful summaries.

## Goals

- Learn Modern C++
- Practice file handling
- Practice parsing
- Learn CMake
- Build production-quality code
